# jrf_vrc_parts

VRChat 用の小さな Modular Avatar の部品集です。JRF が VRChat でワールドを取材・撮影するために、Claude Code(Claude Opus 5.5)と作って、実際に使っているものです。似たものはほかにもありますが、せっかくなので置いておきます。

[English](README.en.md)

| 部品 | ひとことで |
|---|---|
| [MyAirPlatform(空中の椅子)](#myairplatform空中の椅子) | 空中にワールド固定の椅子を出し、**ほかの人**を座らせる |
| [MyTransparent(透明)](#mytransparent透明) | メニューで自分の姿を消す。ほかの人の画面でも、ちゃんと元に戻る |
| [MyLight(ライト)](#mylightライト) | 撮影用のライト。スポットと「人物だけ」を照らす光 |

ダウンロードは [Releases](https://github.com/JRF-2018/jrf_vrc_parts/releases) から(ログインは要りません)。部品ごとに unitypackage になっています。Releases はまとまりごとにタグを分けています。この 3 つは `myparts-v<版>`(最新は [myparts-v0.1.0](https://github.com/JRF-2018/jrf_vrc_parts/releases/tag/myparts-v0.1.0))です。

## 必要なもの

- Unity 2022.3、VRChat SDK(Avatars)
- [Modular Avatar](https://modular-avatar.nadena.dev/ja/)(VCC か ALCOM などで入れてください)
- 作った環境: Unity 2022.3.22f1、VRChat SDK 3.10.6、Modular Avatar 1.19.0、NDMF 1.15.0

## 使い方(共通)

1. unitypackage をプロジェクトに入れる(`Assets/Avatar/<部品の名前>/` に入ります)。
2. その中の prefab を、Hierarchy でアバターの直下にドラッグする。
3. ふつうにアップロードする。

メニューは日本語だけです。どれも Expressions メニューのトップに 1 項目を足します。

## MyAirPlatform(空中の椅子)

自分のアバターの前の空中に、VRC Station(座れる椅子)を出して、ワールドに固定します。**ほかの人**がそれをクリックして座ります。カメラ役が椅子を出し、モデル役を空中に座らせて撮る、という使い方をしています。

- **自分では座れません。** VRChat では自分のアバターの椅子は自分でクリックできないためです(自分のアバターは PlayerLocal というレイヤーで、クリックの判定を素通りします)。
- メニュー「空中の椅子」:
  - 椅子を出す(トグル): 出した瞬間の自分の前に固定します。消して出し直すと、その場所に置き直します。
  - 高さ(20 m)(ダイヤル): 0 で足元、1 で 20 m 上。置いたあとも動かせます。
  - 前へ(ダイヤル): 0〜5 m 前。既定 0.3(1.5 m)。
  - 色を付ける(トグル、既定 ON): 座る所にオレンジの板を出します。撮るときは切ってください。
- 同期するパラメーターは 19 bit(`MyAirPlatform/On`・`Replace`・`Height`・`Forward`・`Color`)。

気をつけること:

- **高さ 0 では、椅子(と板)が地面に少し埋まります。** 出したら少し上げてください。
- **出し直したあと 2 秒ほどは、ほかの人の画面で椅子が前の場所に見えることがあります。** 2 秒後に直ります。
  - ほかの人がこちら(椅子を出した人)を見ていない間は、その人の画面で椅子の追従の計算が止まるらしく、出し直しても前の場所のまま固まることがありました。いろいろ試した結果、「椅子が落ち着いたあとに、同期するパラメーターが 1 回変わる」と、見ていない人の画面でも置き直されることが分かったので、出してから 2 秒後にアバター自身が隠れたパラメーター(`MyAirPlatform/Replace`)を 1 回だけ反転させています。わざとでたらめに出し入れ・連打しても、見ていない人の画面でずれないことを確かめました。
- 座っている人がいる状態で、あとから入ってきた人には、座った人が変な場所(原点など)に見えることがあるそうです(VRChat の既知の問題)。
- 座ったまま高さを変えると、座っている人の画面では、一度視点を動かすまで高さが反映されないことがあります。

## MyTransparent(透明)

メニューのトグル「透明」で、アバターの `Body`(アバターの直下のメッシュ)を消します。VRoid から VRM Converter for VRChat で変換したアバターは体のメッシュが `Body` 1 つなので、置くだけで効きます。ほかのアバターは、置いたあと MA Object Toggle の対象を、消したいメッシュに指定し直してください。

- 同期するパラメーターは 1 bit(`MyTransparent/On`)。
- 中に、**いつも出ている完全に透明な箱**(腰に 30 cm、アルファ 0)が入っています。描く物が 1 つもなくなると、ほかの人の画面でアバターのアニメーションの更新が止まり、透明を切っても姿が戻らない(アバターのリセットまで)ことがあったためです。この箱があると、透明を切ればほかの人の画面でもすぐ戻ります。箱は画面にも写真にも写りません。

## MyLight(ライト)

撮影用のライトを、自分の首の前に付けます(頭に付けると、自分の画面では VRChat が頭を縮めるため、位置がずれました)。暗い場所でモデルを照らすためのものです。

- メニュー「ライト」:
  - スポット(トグル): 前を照らすスポットライト。
  - 人物だけ(トグル): アバター(プレイヤー)だけを照らす点光源。床や壁は明るくなりません。
  - 影(トグル): 影を落とす(VRChat の画質の設定で影が切れていると出ません)。
  - 強さ・高さ・範囲・角度(スポット)・上下の向き(スポット)(ダイヤル): 高さは -1.5〜+4 m、上下の向きは真上〜真下。
- 同期するパラメーターは 49 bit。ダイヤルの値は保存されます。
- ほかの人の画面では、その人の安全設定(Safety)でライトが消えることがあります。
- 目安: 「人物だけ」0.75 くらいで、白い服や肌がはっきり明るくなります。

## ソース

`src/` に、それぞれの prefab を作るエディタ用のスクリプト(`*Builder.cs`)を置いています。prefab はこれで作りました(Unity のバッチモードで動かします)。作りながら試した経緯も、コメントに残しています。unitypackage には入れていません。
